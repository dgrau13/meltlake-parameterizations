# meltlake-parameterizations

Code to reproduce Grau et al. (2025) in *Nature Communications*
Danielle Grau, Azeez Hussain, Alexander A. Robel 
Predicting Mean Depth and Area Fraction of Antarctic Supraglacial Melt Lakes with Physics-Based Parameterizations, 
15 July 2025, available in *Nature Communications* [(https://doi.org/10.1038/s41467-025-61798-8)](https://www.nature.com/articles/s41467-025-61798-8)
